# Javada — тренажёр Java для начинающих

**Javada** — это учебный сайт, который вы запускаете **на своём компьютере**. Нужны лишь браузер, Java и Python: устанавливать IntelliJ IDEA или разбираться в Git для первого урока не обязательно. Вы читаете объяснение, повторяете пример, решаете задачу и получаете подсказку или реальную ошибку компилятора.

В курсе **22 модуля, 99 уроков и 679 заданий**: от первых переменных до ООП, коллекций и знакомства с инструментами разработки. В каждом уроке есть переписывание кода по образцу, три основных уровня и **необязательный хард**. Хард даёт дополнительные очки и достижение, но не мешает двигаться дальше. Попытки не ограничены.

> **Это тренажёр, а не готовая профессия.** Чтобы стать разработчиком, кроме уроков нужны самостоятельная практика, свои проекты, документация, дополнительные материалы, разбор чужого кода и обратная связь. Навыки, а не набранные XP, имеют значение.

## Начать с нуля

### 1. Установите две программы

- **Java Development Kit (JDK) версии 17 или новее** — скачайте с [официального сайта Eclipse Temurin](https://adoptium.net/temurin/releases/?version=21). Для первого раза подойдёт **Temurin 21 LTS**, пакет **JDK** для вашей операционной системы. **JRE недостаточно**: в JDK есть компилятор `javac`, который проверяет решения.
- **Python версии 3.10 или новее** — скачайте с [официального сайта Python](https://www.python.org/downloads/). Он нужен, чтобы запустить сайт локально, а не для выполнения учебных Java-программ. При установке Python на Windows включите **Add python.exe to PATH**; если установщик JDK предлагает добавить Java в `PATH`, согласитесь.

После установки откройте **новое** окно Командной строки (`cmd`) на Windows или Терминала на macOS/Linux — это окно, в которое вводят команды. `PATH` — список папок, где система ищет установленные программы. Проверьте Java командами `java -version` и `javac -version`. Для Python выполните `python --version` на Windows или `python3 --version` на macOS/Linux. Номера версий должны быть не ниже **17** для Java/Javac и **3.10** для Python. Если `javac` не найден, проверьте установку **JDK**, не JRE, и путь `PATH` — подробные советы есть в [инструкции](java-trainer/README.md#если-что-то-не-работает).

### 2. Скачайте файлы проекта

Откройте [страницу проекта на GitHub](https://github.com/ArtemDobrokvashin/java_learning), нажмите **Code → Download ZIP**, распакуйте архив и откройте в нём папку **`java-trainer`**. Если предпочитаете Git, скачайте его с [официального сайта](https://git-scm.com/downloads/) и выполните `git clone https://github.com/ArtemDobrokvashin/java_learning.git`, затем откройте `java_learning/java-trainer`.

Откройте терминал **внутри `java-trainer`**: на Windows в Проводнике этой папки щёлкните адресную строку, наберите `cmd` и нажмите Enter; на macOS/Linux введите в Терминале `cd ` и перетащите туда папку `java-trainer`, затем Enter. В нужной папке видны файлы **`server.py`** и **`requirements.txt`**.

### 3. Вставьте команды для своей системы

Эти команды создают папку `.venv` с отдельным Python, устанавливают необходимый пакет и запускают сайт. Выполняйте их **по очереди из папки `java-trainer`**. Интернет нужен для первой установки пакета.

**Windows — Командная строка (`cmd`):**

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py
```

**macOS/Linux — Терминал:**

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python server.py
```

Не закрывайте окно с работающим сервером. Если браузер не открылся сам, перейдите на **[http://localhost:8000](http://localhost:8000)** (именно `http`, не `https`). Выберите первый доступный модуль и первый урок. **Не открывайте `frontend/index.html` двойным щелчком** — проверка кода работает через сервер.

Для остановки нажмите **Ctrl+C** в окне сервера. В следующий раз откройте терминал в папке `java-trainer` и выполните **только последнюю команду** из блока для своей системы: переустанавливать пакет не надо. Если что-то не получилось, в [пошаговом руководстве по запуску](java-trainer/README.md#запуск-с-нуля--по-шагам) есть дополнительные пояснения и [ответы на типичные ошибки](java-trainer/README.md#если-что-то-не-работает).

## Зачем пробовать, если вы не планируете писать Java

- **Project manager** лучше поймёт, зачем нужны проверки, исправление ошибок и время на реализацию, и сможет предметнее обсуждать риски с командой.
- **Product manager / product owner** научится точнее описывать поведение продукта и задавать вопросы про данные, API и технические ограничения.
- **Аналитику, тестировщику, дизайнеру, техническому писателю** знакомство с кодом поможет разбирать логику функций, сценарии ошибок и границы возможностей системы.

Это полезная **основа для общения с разработчиками**, а не замена профильному обучению управлению, дизайну или тестированию. Тем, кто хочет именно в разработку, советуем дополнить задания собственными программами и [официальными материалами Java](https://dev.java/learn/). Темы вроде Spring и Docker здесь объясняются на учебных примерах; для реальной работы с ними нужны отдельные проекты и инструменты.

## Прогресс, плагин и безопасность

Прогресс и черновики сохраняются **локально** в браузере и файле `java-trainer/.javada/progress.json`, а не в облаке. Не очищайте хранилище браузера без необходимости и делайте резервную копию файла прогресса. При возврате после обновления используйте тот же адрес сайта: для браузера `localhost` и `127.0.0.1` — разные хранилища.

По желанию можно решать часть кодовых задач через [плагин для IntelliJ IDEA](java-trainer/idea-plugin/README.md). Он **не нужен для веб-тренажёра** и подключается к **уже запущенному** локальному серверу. IDEA можно получить на её [официальной странице](https://www.jetbrains.com/idea/download/).

Java-код выполняется на вашем компьютере **с вашими правами**. Ограничение времени не делает это безопасной песочницей: запускайте только свой или доверенный код и не публикуйте локальный сервер в интернете. В публичном предпросмотре проверка Java отключена. Подробности о составе курса, ограничениях и помощи при установке — в [README тренажёра](java-trainer/README.md); техническое устройство проекта — в [руководстве для разработчиков](java-trainer/docs/DEVELOPMENT.md).
