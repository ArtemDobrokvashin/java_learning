## Быстрый старт

### 1. Установите Java и Python

| Нужно | Что выбрать |
| --- | --- |
| [**JDK 17+**](https://adoptium.net/temurin/releases/?version=21) | Для простого старта — **Temurin 21 LTS, пакет JDK**, не JRE. В нём есть компилятор `javac`. |
| [**Python 3.10+**](https://www.python.org/downloads/) | На Windows отметьте **Add python.exe to PATH**. |

После установки откройте **новый терминал**. Убедитесь, что `java -version` и `javac -version` показывают версию 17 или новее. Для Python проверьте `python --version` на Windows или `python3 --version` на macOS/Linux.

**Git, Node.js, Docker, Maven и IntelliJ IDEA для первого урока не нужны.**

### 2. Скачайте проект

На [странице репозитория](https://github.com/ArtemDobrokvashin/java_learning) выберите **Code → Download ZIP**, распакуйте архив и откройте папку **`java-trainer`**.

Откройте терминал **в этой папке**: на Windows в адресной строке Проводника введите `cmd`; на macOS/Linux перейдите в неё командой `cd`. Рядом должны лежать `server.py` и `requirements.txt`.

### 3. Выполните команды по одной

**Windows — Командная строка (`cmd`):**

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py
```

**macOS / Linux — Терминал:**

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python server.py
```

Оставьте терминал открытым и перейдите на **[http://localhost:8000](http://localhost:8000)**. Выберите первый модуль — можно начинать!

> Не открывайте `frontend/index.html` двойным щелчком: проверке кода нужен работающий сервер. Остановить его можно через **Ctrl+C**. При следующем запуске нужна только последняя команда (`… server.py`).

Не получилось? В [инструкции по установке](java-trainer/README.md) есть настройка окружения и [разбор частых ошибок](java-trainer/README.md#если-что-то-не-работает): от «`javac` не найден» до занятого порта и проблем с установкой Flask.

## Данные, безопасность и следующие шаги

- Прогресс и обычные черновики сохраняются в браузере и `java-trainer/.javada/progress.json`. **Незавершённые ответы экзамена — в браузере.** Используйте один и тот же адрес, включая порт; перед обновлением сделайте резервную копию профиля.
- Java выполняется **с вашими правами**, а не в защищённой песочнице. Запускайте только доверенный код, не от администратора и не публикуйте сервер в интернете. В публичном предпросмотре запуск Java отключён.
- Spring, SQL и другие инструменты здесь изучаются в том числе на моделях для стандартного JDK. Настоящие БД и Spring-приложения не запускаются автоматически. **Тренажёр — начало пути, не гарантия профессии:** дополняйте его своими проектами, документацией и код-ревью.
