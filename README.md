# Javada — локальный Java-тренажёр

Приложение и инструкции: **[java-trainer/](java-trainer/README.md)**. 22 модуля, 99 пошаговых уроков и 679 заданий: в каждом уроке есть переписывание кода по образцу и уровни **лёгкий → средний → сложный → необязательный хард**. Хард приносит 90 XP и достижение, но не мешает перейти дальше. Прежние ID заданий и прогресс сохраняются.

```bash
cd java-trainer
pip install -r requirements.txt
python server.py
```

Нужны Python 3.10+ и JDK 17+ для исполнения Java. Браузер откроет `http://localhost:8000`. Прогресс и черновики хранятся в браузере и в локальном `.javada/progress.json` для работы через **[плагин IntelliJ IDEA](java-trainer/idea-plugin/README.md)**. Плагин подключается к уже запущенному серверу и охватывает все 44 прежние задачи с кодом, 99 новых хардов и пять лабораторий; сервер сам он не запускает. В меню «К junior» есть практический маршрут и заготовки двух проектов.

**Безопасность:** компилятор предназначен только для собственного доверенного кода на `127.0.0.1`: лимит 5 секунд не является изоляцией. В публичном предпросмотре Java и общий профиль недоступны. Для установки плагина и сведений о сохранении старых данных см. подробный README.
