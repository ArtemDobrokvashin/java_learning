# Javada — учимся Java шаг за шагом

**Автор: Доброквашин Артем.** [Написать мне в Telegram](https://t.me/Artem_Dobrokvashin).

Javada — это **учебный тренажёр**, который запускается на вашем компьютере и открывается как обычный сайт в браузере. Вы читаете объяснение, смотрите пример, решаете задачу и сразу получаете обратную связь. Когда задача требует написать Java-код, программа на вашем компьютере действительно запускает компилятор Java и показывает ошибку, если она есть. Аккаунт, оплата и отдельный редактор кода для первых шагов **не нужны**.

Внутри — **22 модуля, 99 уроков и 679 заданий**: от переменных и циклов до ООП, коллекций, SQL, Spring, тестов и CI/CD. В каждом уроке есть упражнение «перепишите пример» и уровни **лёгкий → средний → сложный → хард**. Хард можно пропустить: он даёт больше очков опыта (XP) и достижение, но не закрывает путь к следующему уроку. Ошибаться и пробовать снова можно без ограничений.

> **Важно:** Javada помогает учиться, но **одного тренажёра недостаточно, чтобы стать разработчиком**. Понадобятся самостоятельные проекты, практика вне готовых заданий, чтение документации и дополнительных материалов, работа с чужим кодом и обратная связь от других людей. Очки XP — мотивация, а не подтверждение квалификации.

## Что установить: ссылки и простое объяснение

| Что | Зачем нужно | Где скачать |
| --- | --- | --- |
| **Java Development Kit (JDK) 17 или новее** | Включает `java` для запуска программ и **`javac` для проверки ваших решений**. Одна только JRE не подойдёт. Если не знаете, какую версию выбрать, берите Temurin **21 LTS**, пакет **JDK** под свою ОС и архитектуру. | [Eclipse Temurin — официальный сайт Adoptium](https://adoptium.net/temurin/releases/?version=21) ([версия 17](https://adoptium.net/temurin/releases/?version=17)) |
| **Python 3.10 или новее** | Запускает локальное приложение, которое отдаёт уроки браузеру и проверяет код. Java **не заменяет** Python в этой установке. | [Официальная страница загрузки Python](https://www.python.org/downloads/) |
| **Git — необязательно** | Позволяет скачать репозиторий командой `git clone` и получать обновления. Вместо него можно скачать ZIP. | [Официальная страница загрузки Git](https://git-scm.com/downloads/) |
| **IntelliJ IDEA — необязательно** | Нужна **только** если вы захотите решать задачи через дополнительный плагин в IDE. Веб-тренажёр работает без IDEA. | [Официальная страница IntelliJ IDEA](https://www.jetbrains.com/idea/download/) |

**Node.js, Docker и Maven для обычного запуска тренажёра не нужны.** Они пригодятся только для отдельных задач по разработке проекта или самостоятельных приложений позднее.

**При установке на Windows** разрешите добавление Java и Python в `PATH` — список папок, где система ищет программы, — если установщик предлагает такой пункт (у Python обычно написано *Add python.exe to PATH*). После установки **закройте и снова откройте терминал**. На macOS с процессором Apple Silicon выбирайте сборку для **aarch64/ARM64**, для обычного Intel/AMD — **x64**. Не перепутайте **JDK** с **JRE**.

На Debian/Ubuntu можно установить JDK и системные компоненты Python через менеджер пакетов: `sudo apt update && sudo apt install openjdk-17-jdk python3 python3-venv python3-pip`. Затем проверьте, что ваш `python3` имеет версию **не ниже 3.10**; иначе используйте подходящую версию Python для своей системы. Если вы не пользуетесь Linux, эта команда вам не нужна.

## Запуск с нуля — по шагам

### 1. Проверьте установку Java и Python

Откройте **Командную строку (cmd)** на Windows или **Терминал** на macOS/Linux — это окно, в которое вводят команды. Введите команды по очереди:

```text
java -version
javac -version
```

На Windows затем выполните `python --version`; на macOS/Linux — `python3 --version`. Должны появиться номера версий: у Java/Javac **17 или больше**, у Python **3.10 или больше**. Если `java` работает, но `javac` не найден, у вас, скорее всего, установлена не та версия Java или папка `bin` от JDK не добавлена в `PATH` — см. [«Если что-то не работает»](#если-что-то-не-работает).

### 2. Скачайте проект

Без Git: откройте [репозиторий на GitHub](https://github.com/ArtemDobrokvashin/java_learning), нажмите **Code → Download ZIP**, распакуйте архив. Папка после распаковки может называться `java_learning-main`.

С Git: выполните в терминале:

```text
git clone https://github.com/ArtemDobrokvashin/java_learning.git
```

После скачивания найдите **внутри проекта папку `java-trainer`**. Именно в ней лежат `server.py` и `requirements.txt`. Не запускайте `frontend/index.html` двойным щелчком: задания с Java работают только через запущенный сервер.

### 3. Откройте терминал прямо в папке `java-trainer`

- **Windows:** откройте папку `java-trainer` в Проводнике, щёлкните адресную строку сверху, напечатайте `cmd` и нажмите Enter. Откроется командная строка сразу в нужной папке.
- **macOS/Linux:** откройте Терминал, введите `cd ` (с пробелом), перетащите папку `java-trainer` в окно терминала и нажмите Enter. Можно перейти и обычной командой `cd` с полным путём к папке.

Для самопроверки: команда `dir server.py` на Windows или `ls server.py` на macOS/Linux должна показать файл `server.py`. Если файла нет — вы находитесь не в той папке.

### 4. Установите зависимость и запустите приложение

Мы создаём **`.venv` — отдельное окружение Python внутри проекта**, чтобы не менять системные пакеты. Запускайте следующие команды **в той же папке `java-trainer`**, по одной строке.

**Windows (Командная строка / cmd):**

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py
```

Если Windows не узнаёт команду `python`, но работает `py`, замените **только первую строку** на `py -3 -m venv .venv`, а остальные выполните без изменений.

**macOS / Linux (Терминал):**

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python server.py
```

Во время **первой установки** пакетов нужен интернет. После неё сам тренажёр и его шрифты/редактор работают локально. **Оставьте окно с работающим сервером открытым**: если закрыть его, страница перестанет проверять ответы.

### 5. Откройте первый урок

Сервер обычно сам откроет браузер. Если этого не произошло, вручную перейдите на **[http://localhost:8000](http://localhost:8000)** — именно `http`, без буквы `s`. На карте курса откройте **первый доступный модуль**, затем первый урок. Сначала прочитайте объяснение и посмотрите, как выводить переменные; затем попробуйте задания.

Чтобы остановить сервер, вернитесь в его окно и нажмите **Ctrl+C**. Чтобы продолжить в другой день, снова откройте терминал в `java-trainer` и выполните **только последнюю команду** своего списка выше (`... server.py`). Заново устанавливать пакеты каждый раз не надо.

## Как устроено обучение

1. В уроке вы сначала разбираете теорию и пошаговый пример, затем переписываете фрагмент по образцу и решаете лёгкий, средний и сложный уровни. При ошибке появляется подсказка; попытки не ограничены.
2. **Хард** — необязательная задача на самостоятельную программу. За неё положены дополнительные XP и достижение. Если пока трудно — пропустите и вернитесь позже через список уроков.
3. После уроков модуля вас ждёт практика с разными типами заданий; в поздних модулях перед практикой есть небольшой экзамен. Следующие модули открываются постепенно.
4. Код вводится в редакторе внутри сайта. Кнопка **«Запустить проверку»** вызывает настоящий `javac` на **вашем компьютере**: компилятор сообщит об ошибке или программа выполнится с ограничением времени **5 секунд**. Для задач с кодом нужен установленный JDK.
5. В разделе **«К junior»** есть пять лабораторных работ, где решение проверяется на нескольких примерах, а также заготовки двух самостоятельных проектов. Решать их полезно **после** знакомства с основами, но они не заменяют собственные проекты.

Прогресс и черновики сохраняются локально: в браузере и в файле `java-trainer/.javada/progress.json`, чтобы сайт мог обмениваться ими с [необязательным плагином IntelliJ IDEA](idea-plugin/README.md). Для обычного обучения плагин **не нужен**; он не запускает сервер за вас и требует отдельной сборки. Это **не облачный сервис**: для сохранности данных не очищайте хранилище браузера и при необходимости делайте резервную копию файла прогресса. Если вы раньше пользовались тренажёром, откройте его с **того же адреса**, что и прежде: `localhost` и `127.0.0.1` для браузера — разные хранилища. Старые ответы/черновики при обновлении курса в **той же папке** не сбрасываются. Если скачиваете свежий ZIP в **другую** папку, прежний `.javada/progress.json` не окажется там сам: при остановленном сервере скопируйте этот файл из старой папки `java-trainer/.javada/` в такую же папку нового проекта, прежде чем запускать новый сервер. Не удаляйте старую папку, пока не убедитесь, что прогресс на месте.

Напоминания можно включить в настройках по желанию: уведомление браузера работает, пока вкладка открыта; для напоминаний при закрытом браузере скачайте `.ics` и импортируйте его в календарь. Никаких «жизней» или платного доступа для новых попыток нет.

## Кому ещё может быть полезно

Не обязательно становиться Java-разработчиком, чтобы извлечь пользу из знакомства с программированием:

| Кому | Что может пригодиться |
| --- | --- |
| **Project Manager (PM)** | Лучше понимать, почему реализация задачи занимает время: код нужно не только написать, но и проверить, исправить ошибки и доставить пользователям. Проще обсуждать риски и зависимости с командой. |
| **Product Manager / Product Owner** | Легче формулировать понятные требования и проверяемые сценарии, задавать вопросы про ограничения API и обсуждать с разработчиками компромиссы между функциями. |
| **Аналитик, QA-инженер, дизайнер, технический писатель** | Полезнее становится разговор о данных, логике условий, поведении системы и ошибках; легче подготовить тестовые случаи, макеты или документацию, которые учитывают реальное поведение программы. |
| **Предприниматель, студент или просто любознательный человек** | Можно понять, что происходит «под капотом» цифрового продукта, и попробовать автоматизировать небольшую собственную задачу. |

Тренажёр учит **основам Java**, а не заменяет курсы по управлению проектами, продуктовому исследованию, дизайну или тестированию. Чтобы **стать разработчиком**, решайте задачи без подсказки, делайте собственные проекты, изучайте Git, SQL, тесты и реальные инструменты, читайте дополнительную документацию и просите код-ревью. Для продолжения пригодятся [официальные материалы Java](https://dev.java/learn/), [руководства Spring](https://spring.io/guides) и [документация Git](https://git-scm.com/doc). Подбирайте дополнительные статьи и книги под конкретные пробелы в знаниях — не ограничивайтесь одной платформой.

## Если что-то не работает

| Что вы видите | Что попробовать |
| --- | --- |
| `javac` не распознаётся или на сайте написано «JDK не найден» | Установите именно **JDK**, не JRE, и откройте **новое** окно терминала. Выполните `javac -version` в том же окне, из которого запускаете сервер. На Windows проверьте, что папка `bin` установленного JDK есть в переменной `PATH` (или переустановите JDK с опцией добавления в PATH). Затем перезапустите сервер. |
| `python` не распознаётся на Windows | Попробуйте `py -3 --version` и `py -3 -m venv .venv`; если `py` тоже отсутствует, переустановите Python с опцией **Add python.exe to PATH**. |
| `No module named flask` | Вы, вероятно, запустили **другой** Python. Установите зависимости командой с `.venv` из шага 4 и запускайте сервер тем же `.venv`-Python. |
| `can't open file 'server.py'` или «файл не найден» | Перейдите в папку `java-trainer`, где лежит `server.py`, а не в корень `java_learning` или `frontend`. |
| Адрес `localhost:8000` не открывается | Убедитесь, что команда запуска сервера всё ещё работает в терминале; откройте **http://localhost:8000**, не `https://`. |
| Порт 8000 уже занят | На Windows **cmd** выполните `set TRAINER_PORT=8001`, затем `.venv\Scripts\python.exe server.py`; на macOS/Linux — `TRAINER_PORT=8001 ./.venv/bin/python server.py`. Откройте **http://localhost:8001**. Плагину IDEA тоже укажите порт 8001. |
| На Linux при установке пакетов появляется `externally-managed-environment` | Не устанавливайте Flask в системный Python через `sudo pip`. Используйте `.venv` из шага 4; если `venv` отсутствует, установите пакет `python3-venv`. |

Если вопрос остался, напишите автору в [Telegram](https://t.me/Artem_Dobrokvashin) и приложите текст ошибки **без паролей и личных данных**.

## Честные ограничения и безопасность

- Выполнение Java-кода происходит **с правами вашего пользователя**. Пять секунд на запуск — защита от зависшего цикла, **не безопасная песочница**. Вводите только свой или доверенный код; не открывайте доступ к локальному серверу из интернета и не запускайте его от администратора.
- Некоторые темы (Spring, SQL, Docker) в заданиях объясняются на примерах, которые можно запустить на стандартном JDK: настоящий Spring-сервер, база данных или Docker **не поднимаются автоматически**. Для практики с ними понадобятся отдельные проекты и материалы.
- Большинство задач с кодом сверяют один ожидаемый вывод; лаборатории — несколько входов. Успех в тренажёре **не доказывает**, что решение верно во всех случаях, и **не гарантирует трудоустройство**.
- Для браузерного предпросмотра, открытого по публичному адресу, проверка Java и доступ к личному профилю отключены. Полноценная работа с кодом — только при запуске на своём компьютере.
