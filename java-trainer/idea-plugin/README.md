# Плагин JavaДа для IntelliJ IDEA

Плагин — клиент **уже запущенного** локального Flask-тренажёра. Он **не устанавливает и не запускает** Python-сервер, JDK, Docker или зависимости курса. Каталог включает **44 прежние задачи с кодом** (по две на модуль), **99 необязательных хардов** (по одному на урок) и пять лабораторий. Теория, переписывание кода и обязательные уровни проходятся в браузере.

## Сборка и установка

1. Установите **JDK 17+**, IntelliJ IDEA Community/Ultimate **2024.1+**; для первого скачивания Gradle и IDE SDK при сборке потребуется интернет. В каталоге `java-trainer/idea-plugin` выполните `./gradlew buildPlugin` (Windows: `gradlew.bat buildPlugin`). Сборка создаст ZIP в `build/distributions/` (папка исключена из Git).
2. В IDEA откройте **Settings → Plugins → ⚙ → Install Plugin from Disk**, выберите этот ZIP и перезапустите IDE. Откройте любой Java-проект и окно **JavaДа** справа.
3. В отдельном терминале запустите Flask из каталога `java-trainer`: `pip install -r requirements.txt`, затем `python server.py`. Проверьте, что доступны `javac -version` и `java -version` в *том же терминале*. По умолчанию сервер слушает `127.0.0.1:8000`. Если используете `TRAINER_PORT=8001`, впишите **8001** в поле порта плагина и нажмите **Обновить**. Удалённый URL указать нельзя: клиент всегда подключается только к `127.0.0.1`.
4. Выберите категорию «Практика · 44», «Хард · 99», «Лаборатории · 5» или «Все задачи»; можно найти задание по ID, модулю или тексту. Нажмите **Открыть Main.java**, напишите решение в обычном редакторе IDEA и **Проверить решение**. Ответ отправляется в тот же `/api/compile`, что и веб-редактор. Показаны настоящие ошибки `javac`, вывод программы и результат проверки. Подсказку можно открыть отдельно.

Файл `Main.java` в IDE — временный редактор, а не изменение исходников вашего Java-проекта. Изменения сохраняются в черновик на Flask-сервере автоматически (после короткой паузы) и по кнопке **Сохранить черновик**. При повторном открытии задачи на этом компьютере берётся сохранённый вариант. Если сервер недоступен, уже открытый редактор не стирается: запустите сервер и повторите сохранение. **Не закрывайте IDE с несохранённым ответом при выключенном сервере.** Кнопка «Обновить» получает последние XP и отметки из веб-приложения.

## Как работает общий прогресс

Локальный профиль находится в `java-trainer/.javada/progress.json` (или каталоге `JAVADA_PROFILE_DIR`, если он задан **серверу**). При первом открытии веб-тренажёра старый `localStorage` **копируется** в этот профиль: прежние XP, отметки, история, настройки и черновики остаются в браузере. Откройте веб-приложение **с того же адреса, что использовали раньше** (`localhost` и `127.0.0.1` имеют разный `localStorage`), чтобы его старые данные перенеслись; затем они станут видны в IDEA после «Обновить». Веб-приложение периодически объединяет локальную и серверную копии. Если IDEA была запущена первой, старые награды после импорта не начисляются повторно.

За каждую успешно проверенную прежнюю задачу практики IDE записывает награду один раз (50 XP); за хард — 90 XP **один раз** и достижение `mastery:<id-урока>`. Неуспешная компиляция, неправильный вывод и отключённый JDK не дают XP. Лаборатории без XP отмечаются пройденными лишь после всех четырёх серверных проверок. Решение двух кодовых задач в IDE **не завершает весь практикум** автоматически: оставшиеся пять заданий и порядок открытия модулей — часть веб-курса. Необязательный хард не нужен для перехода к следующему уроку и доступен отдельно после обязательных уровней.

Профиль хранится только на этом компьютере: **не облачная синхронизация**. Сброс через настройки веб-приложения удалит локальный общий профиль и его браузерную копию. Если вы храните его в резервной копии, не публикуйте личные черновики и историю.

## Ограничения и безопасность

Сервер исполняет ваш код под правами вашего пользователя. Ограничение исполнения пятью секундами **не песочница**. Используйте только собственные доверенные решения и не публикуйте порт Flask; при `TRAINER_HOST=0.0.0.0` компиляция и доступ к профилю автоматически отключены. Для продвинутых тем (Spring, SQL, Docker, GitLab) задачи с кодом **моделируют принципы на стандартном JDK**, не загружают сторонние библиотеки и не запускают настоящий Spring/БД/Docker. Задачи практики и харды проверяют один вывод, а не все возможные входы; для нескольких входов используйте лаборатории.

**Проверки проекта:** Python/JS-тесты проверяют каталог, маршрутизацию всех ID, миграцию XP и сохранение черновиков. В этой рабочей среде отсутствуют JDK и доступ к репозиториям JetBrains/Gradle; сборка ZIP и запуск плагина внутри IDEA здесь не выполнялись. Выполните `./gradlew buildPlugin` на локальной машине с JDK и сетью перед установкой.
