# Плагин «JavaДа» для IntelliJ IDEA

Полнофункциональный автономный плагин на **Kotlin** для **IntelliJ IDEA 2025.3+**, который **полностью заменяет браузер** для пользователей, предпочитающих учиться непосредственно в IDE. При этом пользователи, совмещающие работу в браузере и в IDE, видят единый прогресс благодаря двусторонней синхронизации через общий локальный профиль `java-trainer/.javada/progress.json`.

Курс, доступный в плагине в полном объёме:
- **22 модуля** и **99 уроков** с подробной теорией, примерами кода и пошаговыми разборами;
- **825 заданий курса** (включая образец кода, тесты, заполнение пропусков, сопоставление пар, конструктор кода Парсонса, кодовые задачи, стоп-уроки и **146 экзаменационных заданий**);
- **22 финальных мини-экзамена** (по 5–8 задач без подсказок в конце каждого модуля);
- **5 лабораторных работ** раздела «К junior» с проверкой на нескольких входных наборах.

## Ключевые возможности и архитектура

### 1. Tool Window «JavaДа» и дерево курса (`CourseTree.kt`)
- Иерархическое представление всего курса: **Модули → Уроки → Задания / Стоп-уроки / Финальная практика → Мини-экзамены + Лабораторные работы**.
- Наглядные иконки статусов для каждого элемента:
  - **Выполнено** (`AllIcons.RunConfigurations.TestPassed`);
  - **Доступно** (`AllIcons.Actions.Execute` / `AllIcons.Nodes.Book`);
  - **Заблокировано** (`AllIcons.Diff.Lock`).
- Мгновенный поиск по дереву с клавиатуры (`TreeSpeedSearch`) и текстовая фильтрация по номеру модуля, теме урока, ID или условию задачи с сохранением раскрытых веток.

### 2. Встроенный просмотр теории в Split View (`JavadaToolWindowFactory.kt`)
- Панель `JBSplitter` отображает теорию текущего урока в формате Markdown/HTML прямо внутри IDE (с поддержкой светлой темы и темы Darcula):
  - цель урока (`objective`), основные разделы теории (`paragraphs`) и фрагменты кода;
  - разбор примера (`walkthrough`), типичные ошибки (`pitfall`), углублённый материал (`deepDive`) и практические сценарии (`useCase`);
  - пошаговое руководство (`guide`) с полным запускаемым примером `Main.java` и ожидаемым выводом.

### 3. Рабочее пространство задачи и работа с `Main.java`
- При выборе кодовой задачи в основном редакторе IDEA автоматически открывается виртуальный файл `Main.java` (или иной целевой файл задачи) с начальным шаблоном `starterCode` либо ранее сохранённым черновиком из `.javada/progress.json`.
- Все изменения в редакторе автоматически сохраняются в черновик с debounce **600 мс** (`DocumentListener`), а также принудительно сбрасываются на диск при закрытии проекта или запуске проверки.
- Проверить решение можно кнопкой **«Проверить решение»** в нижней панели плагина, кнопкой в главном тулбаре IDE или сочетанием клавиш **`Ctrl+Shift+Enter`** из контекстного меню редактора (`CheckTaskAction`).

### 4. Двухрежимный нативный механизм проверки (`TaskChecker.kt`)
Плагин проверяет задачи **нативно через локальный JDK** с использованием `GeneralCommandLine`, не требуя запущенного Flask-сервера `server.py`:

1. **Режим сравнения `stdout` с `expected.txt` и эталонными данными курса (`STDOUT_EXPECTED`)**:
   - Компилирует `Main.java` через `javac -encoding UTF-8` во временной директории с принудительными UTF-8 флагами (`-Dfile.encoding=UTF-8`, `-Dstdout.encoding=UTF-8`, `-Dsun.stdout.encoding=UTF-8`).
   - Запускает `java Main`, передаёт входные данные в `stdin` и сверяет нормализованный стандартный вывод (`stdout`) с файлом **`expected.txt`** (при наличии в каталоге задачи `tasks/<id>/expected.txt`), с тест-кейсами из `private/lab_cases.json` (для лабораторных работ) или с полем `expectedOutput` из JSON-файлов `frontend/data/module-XX.json`.
2. **Режим запуска JUnit 5 тестов (`JUNIT_TESTS`)**:
   - Для задач и проектов, проверяемых модульными тестами, компилирует код решения вместе с тестовым классом (`*Test.java`) и запускает **`org.junit.platform.console.ConsoleLauncher`** (`junit-platform-console-standalone.jar`, упакованный в ресурсы плагина) через `GeneralCommandLine`, анализируя дерево результатов и стектрейсы ошибок.
3. **Валидация интерактивных заданий**:
   - Нативно проверяет задания типов `copy` (по потоку лексем Java), `choice`, `fill` (включая числовые диапазоны `integerRange` и список синонимов `accepted`), `matching` и `parsons` (с учётом отступов и допустимых перестановок `alternativeOrders`).

### 5. Менеджер прогресса и синхронизация с браузером (`ProgressManager.kt`)
- **Атомарная запись**: сохранение в `java-trainer/.javada/progress.json` выполняется через запись во временный файл `.progress-*.tmp`, сброс файлового кэша на диск (`FileChannel.force(true)`) и атомарное перемещение `Files.move(..., ATOMIC_MOVE, REPLACE_EXISTING)`.
- **Отслеживание внешних изменений**: фоновый поток через `java.nio.file.WatchService` и проверку `lastModifiedTime` отслеживает изменения `progress.json` со стороны браузера / Flask-сервера в реальном времени и выполняет монотонное слияние (`mergeProfiles`) без дублирования наград или потери черновиков.
- **Геймификация**: идемпотентное начисление XP через `xpLedger` (50 XP за практику, 90 XP и бейдж `mastery:<id>` за хард, бонус +10% за серию от 2 дней, вехи 7 и 30 дней).

### 6. Режим мини-экзамена
- Последовательное открытие **5–8 экзаменационных задач** выбранного модуля в специальном режиме **без подсказок**.
- Автоматический подсчёт правильных ответов по завершении всех шагов.
- При результате **≥ 80%** (`correct * 100 >= 80 * total`, без округления вверх) начисляются бонусные XP (`310–520 XP`), выдаётся достижение `exam:mXX`, а следующий модуль автоматически разблокируется в `.javada/progress.json`. При результате ниже 80% устанавливается часовой таймер до пересдачи (`retryAt`).

### 7. Безопасность и контроль ресурсов
- **Предупреждение при первом запуске**: перед первой компиляцией и запуском кода плагин показывает диалог подтверждения безопасности, уведомляющий, что код исполняется локально с правами пользователя ОС.
- **Таймаут выполнения (5 секунд)**: компиляция ограничена 10 секундами, а выполнение программы или JUnit-тестов — **5 секундами** (`process.waitFor(5000, TimeUnit.MILLISECONDS)`). Зависший процесс и его дочерние процессы принудительно завершаются через `Process.destroy()` и `Process.destroyForcibly()`.
- **Ограничение памяти и вывода**: для запускаемой JVM задаются лимиты кучи (`-Xmx96m` / `-Xmx128m`), а захватываемый вывод `stdout`/`stderr` ограничен 12 КБ.

## Технический стек

- **Язык**: Kotlin `2.1.20`
- **Система сборки**: Gradle `8.12.1` + `org.jetbrains.intellij.platform` `2.3.0`
- **Java Toolchain**: **Java 25** (`java.toolchain.languageVersion = JavaLanguageVersion.of(25)`) с поддержкой `--enable-preview` в `javacOptions` и `jvmArgs`
- **Целевая версия IDE**: **IntelliJ IDEA 2025.3+** (Community / Ultimate, `sinceBuild = 253`)
- **Библиотеки**: `Gson 2.11.0`, `kotlinx-serialization-json 1.8.0`, `junit-platform-console-standalone 1.11.4`

## Сборка, установка и тестирование

### 1. Сборка архива плагина

Перейдите в каталог `java-trainer/idea-plugin` и запустите задачу `buildPlugin`:

**macOS / Linux:**
```bash
cd java-trainer/idea-plugin
./gradlew buildPlugin
```

**Windows (`cmd` / PowerShell):**
```bat
cd java-trainer\idea-plugin
gradlew.bat buildPlugin
```

Собранный архив плагина будет создан в каталоге:
```text
java-trainer/idea-plugin/build/distributions/javada-idea-plugin-2.0.0.zip
```

> Для запуска отладочного экземпляра IDE с уже установленным плагином выполните `./gradlew runIde`.

### 2. Установка в IntelliJ IDEA (Install Plugin from Disk)

1. Откройте **IntelliJ IDEA 2025.3+**.
2. Перейдите в **Settings → Plugins → ⚙️ → Install Plugin from Disk…**.
3. Выберите архив `java-trainer/idea-plugin/build/distributions/javada-idea-plugin-2.0.0.zip`.
4. Нажмите **OK** и перезапустите IDE.

### 3. Работа с курсом в IDEA

1. Откройте каталог репозитория `java_learning` (или `java-trainer`) как проект в IntelliJ IDEA и убедитесь, что в **File → Project Structure → Project** выбран JDK 17–25.
2. Откройте панель **«JavaДа»** на правой боковой панели IDE.
3. Выберите модуль и урок в дереве курса:
   - изучайте теорию и примеры в верхней части панели Split View;
   - пишите код решения в автоматически открывающемся файле `Main.java`;
   - нажимайте **«Проверить решение»** (или `Ctrl+Shift+Enter`) для мгновенной нативной проверки и начисления XP в общий файл `.javada/progress.json`.
